# 技能：构建平台并启动（platform-go）

适用：协调平台 liyou-platform.exe 的编译、凭据配置与本地/生产启动。

## 1. 前置

- Go 1.22+：`D:\soft\go\bin`（加入 PATH；如遇工具链版本错配，设 `$env:GOTOOLCHAIN='local'`）
- PostgreSQL 在远端（192.168.5.9:5432/liyoup2p），本机无需安装
- 凭据配置文件：`platform-go\.env`（敏感，已 gitignore，绝不入库）

## 2. 构建

```powershell
cd D:\dev\liyou\liyoup2p\platform-go
$env:Path = 'D:\soft\go\bin;' + $env:Path
.\build.ps1        # 产出 ..\liyou-platform.exe（约 10MB）
```

手动等价命令：`go build -ldflags "-s -w" -o ..\liyou-platform.exe ./cmd/platform`

质量门槛（发版前必须全绿）：

```powershell
go build ./...
go vet ./...
go test -count=1 ./internal/api/
```

## 3. 配置 .env（必需凭据，缺失拒绝启动）

`platform-go\.env` 四个键：

```
LIYOU_DSN=host=192.168.5.9 port=5432 user=postgres password=<密码> dbname=liyoup2p sslmode=disable
LIYOU_JWT_SECRET=<64 字节十六进制随机值；生成：openssl rand -hex 64 或 PowerShell CSPRNG>
LIYOU_ADMIN_PASSWORD=<种子账号 admin 密码>
LIYOU_SUPERADMIN_PASSWORD=<种子账号 superadmin 密码>
```

注意：
- JWT_SECRET 一旦轮换，所有已签发的设备令牌/服务端令牌全部失效，需重签（见技能 6 的重注册流程）
- 密码需满足复杂度策略：≥10 位且含大写/小写/数字/特殊字符（`internal/api/password_policy.go`）

## 4. 启动与验证

```powershell
.\start-platform.ps1     # 读取 .env 注入环境变量后启动 liyou-platform.exe
```

- 端口：HTTP/WS `:8900`，TCP 中继 `:8901`
- 验证登录：`POST http://127.0.0.1:8900/api/auth/login`，body `{"username":"admin","password":"...","tenant":"platform"}`
- 健康检查：`GET http://127.0.0.1:8900/api/update/latest?ch=pc`（免鉴权，返回 200 即 API 可用）

## 5. 注意事项

- 重启平台会瞬断全部设备信令，Agent 每 5 秒自动重连，无需人工干预
- 平台不经手业务流量，重启只影响信令与新会话建立
- 修改 .env 后必须重启平台才生效
