# 励联 LiLink 产品说明

> 远程内网穿透 · 安全直达 · 降低勒索风险

## 一、产品是什么

励联 LiLink 是一款面向企业和个人用户的**内网远程访问工具**。

当您在公司或家里有一台电脑、服务器或 NAS，需要在办公室外访问它上面的文件、软件或管理页面时，传统做法是把内网服务"暴露到公网"——任何人都能在互联网上扫描到这个入口，这也是勒索病毒、黑客入侵最常见的突破口。

励联 LiLink 的做法完全不同：

- **不在公网开任何门**。您的内网设备始终藏在路由器后面，互联网上扫描不到。
- **只有您自己能进**。所有访问都必须先登录：租户 + 账号 + 密码 + 设备身份，四重核对。
- **通道即用即关**。连接建立时临时开通、断开即关闭，不产生常驻入口。

一句话总结：**把"在公网留一扇常开的门"变成"只有持钥匙的人敲特定门牌才临时开门"**。

## 二、它能帮我防勒索病毒吗

### 能做到的

1. **消除最大的入侵入口**。勒索病毒团伙的主要手法是 7×24 小时扫描全网开放的远程端口（远程桌面、文件共享等），爆破密码后入侵加密。使用励联后，这些端口不再暴露在互联网上，扫描攻击者根本找不到入口。
2. **陌生连接一律拒绝**。未登录、未授权的设备无法建立任何连接；即使有人猜测到线路，没有您的账号和设备身份也进不来。
3. **访问范围可控**。您可以精确指定"允许访问哪台内网机器的哪个服务"，最小化授权；不需要的服务不开通。
4. **外网线路全加密**，传输内容在公网上不可被窃听、篡改。

### 不能做到的（重要，请如实告知客户）

励联 LiLink 能大幅**降低**感染勒索病毒的概率，但**没有任何软件能保证 100% 防病毒**。以下情况仍需客户自行防范：

- **电脑自身中毒**：点击钓鱼邮件附件、插入带毒 U 盘、下载捆绑木马的软件、系统长期不打补丁——这些与内网穿透无关，任何组网产品都防不住。
- **账号密码泄露**：把账号借给他人、密码过于简单、在陌生电脑上登录后未退出。
- **已授权设备失陷**：一台已经登录励联的电脑如果中毒，它"本来就是合法用户"，可以通过已开通的规则访问内网服务。因此内网服务器上的重要数据仍应**定期备份到离线介质**。
- **服务器弱密码**：内网机器自身的登录密码如果太弱，被已入侵的内网设备横向感染。

**推荐的安全组合**：励联 LiLink（收敛入口）+ 服务器定期备份（最后一道防线）+ 杀毒软件与系统更新（基础防护）+ 强密码（第一道防线）。

## 三、为什么不用担心"别人顺着线路打进来"

客户经常担心：你们在网络上"打洞"、"探测"，会不会给黑客留了口子？

我们的回答（可以直接引用给客户）：

1. **探测不产生入口**。客户端连接时会向腾讯、小米等大厂提供的公共探测服务询问"我的出口地址是什么"，这个动作只是问一句话，不在您的路由器上开任何门，也不会向这些服务泄露任何内网信息。
2. **"洞"只对熟人开**。连接提速时的临时通道，只允许您自己账号下已登录的设备对通，且持续时间以秒计。第三方无法伪造身份加入，也搜不到这个临时通道。
3. **兜底线路同样有身份验证**。少数网络环境下会经由我们的中转服务器转发流量，同样全程加密并校验双方身份，中转服务器上不存储任何业务数据。
4. **独立安全顾问结论**：本产品的攻击面是"平台账号体系"，而不是"您的内网"。守住账号，就守住了全部。

## 五、安装与使用（三步）

1. 在被访问的电脑上安装服务端程序，使用平台为您开通的企业账号登录。
2. 在外出使用的电脑/手机上安装客户端，登录同一账号。
3. 添加一条"我要访问哪台机器的哪个服务"的规则，点击连接即可。

界面上没有任何需要填写的地址、端口等专业信息，普通员工经简单指导即可使用。

> 账号与密码均由平台统一开通和管理：需要新增账号、重置密码，联系平台客服即可，客户无需自行操作。

## 六、常见问题

**Q：数据会经过你们的服务器吗？**
A：优先在通信双方之间直接传输；网络受限时经由中转服务器加密转发，我们看不到内容。

**Q：公司断网了还能用吗？**
A：访问内网需要网络在线；本地局域网内的访问不受影响。

**Q：换电脑、换手机怎么办？**
A：登录账号即可在新设备使用；旧设备可在管理后台一键移除授权。忘记密码同样联系平台客服重置。

**Q：你们会看我的数据吗？**
A：不存储、不解析业务数据；详见《励联 LiLink 软件服务协议》隐私条款。
